skimmd lets an agent read a Markdown file without loading it all.

# Getting started

Two modes: a table of contents, and verbatim line ranges.

## Install

Run `cargo install skimmd`, or grab a binary from the releases.

## Example

See the shape of any file with a single command:

    $ skimmd notes.md
